```javascript
export function movePlayer(player, steps, boardSize) {
  const oldPosition = player.position;
  player.position = (player.position + steps) % boardSize;
  
  // Sprawdź czy gracz przeszedł przez Start
  if (player.position < oldPosition) {
    player.money += 200;
    console.log(`${player.name} przeszedł przez Start! (+$200)`);
  }
}
```

## 📚 Najważniejsze pojęcia z dzisiejszej lekcji

### 1. Separacja odpowiedzialności (Separation of Concerns)
Każdy moduł robi jedną rzecz:
- `diceService.js` – tylko rzuty kostką
- `movementService.js` – tylko ruch
- `displayService.js` – tylko wyświetlanie

### 2. Źródło prawdy (Single Source of Truth)
Dane przechowujemy w jednym miejscu:
- Pozycja gracza w `player.position`
- Definicje pól w `board[]`
- Nie duplikujemy!

### 3. Modulo (`%`) – operacja reszty z dzielenia
```javascript
10 % 3 = 1   // 10 = 3*3 + 1
20 % 20 = 0  // powrót do początku
23 % 20 = 3  // position wraca do 3
```

### 4. Mutacja obiektów
```javascript
// MUTACJA (zmieniamy oryginalny obiekt)
player.position = 5;
player.money += 200;

// vs IMMUTABILITY (tworzenie nowego obiektu)
const newPlayer = { ...player, position: 5 };
```
