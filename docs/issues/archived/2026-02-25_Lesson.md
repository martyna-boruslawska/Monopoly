
### PART 3: Implementing propertyService Functions (25 minutes)

#### 🕐 0:35-0:50 | Buying Logic (15 min)

**Task 4.1:** Create `game/buyProperty.js`

**Pseudocode first:**
```
buyProperty(player, tile):
  1. Check if property is unowned (ownerId === null)
  2. Check if player has enough money
  3. Deduct money from player
  4. Set tile.ownerId = player.id
  5. Add property ID to player.properties[]
  6. Log the transaction
```

**Implementation:**
```javascript
export function buyProperty(player, tile) {
  // Validation
  if (tile.ownerId !== null) {
    console.log(`${tile.name} is already owned`);
    return false;
  }

  if (player.money < tile.price) {
    console.log(`${player.name} doesn't have enough money`);
    return false;
  }

  // Execute purchase
  player.money -= tile.price;
  tile.ownerId = player.id;
  player.properties.push(tile.id);

  console.log(`${player.name} bought ${tile.name} for $${tile.price}`);
  return true;
}
```

**Code Review:**

```javascript
export function payRent(player, owner, tile) {
  // Don't pay yourself
  if (player.id === owner.id) {
    console.log("You own this property!");
    return;
  }

  // Pay rent
  const rentAmount = tile.rent;
  player.money -= rentAmount;
  owner.money += rentAmount;

  console.log(`${player.name} paid $${rentAmount} rent to ${owner.name}`);
}
```

## 📚 Key Concepts Explained

### 1. Ownership Representation

**Why `ownerId` instead of full owner object:**
- Single source of truth: Players array has all player data
- No duplication: Board doesn't copy player information
- Easy to update: Change player money in one place
- Consistency: Board references don't break if player is removed

### 2. Purchasing Validation

```javascript
// Checks happen in order:
1. Is property available? (ownerId === null)
2. Does player have money? (player.money >= price)
3. Execute purchase
4. Update game state atomically
```

### 3. The Dispatcher Pattern

`handleTile()` is called after every move:
- Checks space type
- Routes to appropriate handler
- Keeps turn logic clean and simple
